 Wolfram Demonstrations - Mathematics for AIML

 Overview
This repository documents a self-learning study of core probability and statistical concepts using interactive Wolfram Demonstrations. Through parameter adjustments and visual analysis, these experiments illustrate how key probability distributions and estimation functions behave under varying conditions.

 Topics Covered

 1. Binomial Distribution via Coin Flips
- Simulates repeated coin-tossing trials and records the number of heads obtained per trial.
- Examines the effect of changing the probability of heads (0% to 100%), coin flips per trial (5, 10, or 20), and total number of trials (1 to 10,000).
- Switches between a bar chart of coin flips, the probability mass function (PMF), and the binomial distribution.
- Demonstrates how the distribution approaches a normal curve as the number of trials and flips per trial increase.

 2. Standard Normal Distribution Areas
- Serves as an interactive visual supplement to standard normal cumulative probability tables.
- Computes left-tail, right-tail, and interval probabilities by adjusting lower (z1) and upper (z2) Z-score limits along with the complement option.
- Illustrates the 68-95-99.7 empirical rule, showing the proportion of observations within 1, 2, and 3 standard deviations of the mean.

 3. The Chi-Squared Distribution
- Explores the continuous chi-squared distribution across different degrees of freedom (v).
- Displays both the probability density function (PDF) and cumulative distribution function (CDF).
- Highlights key distribution properties, including the mean (v), variance (2v), and moment generating function (1 - 2t)^(-v/2).

 4. Probability Density vs. Likelihood Function
- Contrasts the probability density function f(x; μ) with the likelihood function L(μ | x0).
- Shows how the PDF evaluates data probabilities for a fixed mean (μ), while the likelihood function treats the observed value (x0) as fixed and peaks at μ = x0.
- Demonstrates how changing the mean (μ), observed value (x0), and dispersion (σ) governs maximum likelihood estimation.

 Tools and Technologies
- Wolfram Demonstrations Project: Used for interactive statistical simulations and parameter exploration.
- Statistical Visualization: Used to analyze density curves, cumulative probability areas, and distribution convergence.

 Learning Outcomes
- Understanding discrete and continuous probability distributions and their governing parameters.
- Modeling independent repeated trials using binomial probabilities and PMFs.
- Interpreting Z-scores, tail probabilities, and the empirical rule on a standard normal curve.
- Analyzing degrees of freedom, moments, and PDF/CDF relationships in chi-squared distributions.
- Distinguishing probability density from likelihood functions in maximum likelihood estimation.
